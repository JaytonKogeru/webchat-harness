# Web Chat Harness — Retired

This skill is no longer an active workflow.

Do not bootstrap new repositories with `WEBCHAT.md` and do not treat this skill as a required repository-control layer.

Its useful principles have been absorbed into [`JaytonKogeru/PAIS`](https://github.com/JaytonKogeru/PAIS): reconstruct live reality, act on the highest-value resolvable gap, verify material work, persist state that must survive session boundaries, and reassess from the new reality.

The remaining files in this repository are preserved only as historical prior art for the experiment.
